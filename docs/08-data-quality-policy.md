# データ品質管理方針

## 1. 基本方針

品質スコアは「使える・使えない」を断定するものではなく、利用者が確認すべき観点を見える化するための補助情報である。

## 2. 品質軸

| 品質軸 | 確認内容 |
| --- | --- |
| 完全性 | 必須項目の欠損率 |
| 一意性 | 重複データの有無 |
| 妥当性 | 緯度経度、日付、コード値が正常か |
| 整合性 | 市区町村コードと名称が一致するか |
| 鮮度 | 基準日・更新日時が許容範囲内か |
| 網羅性 | 全国データか、一部地域のみか |
| 出典性 | 提供元、ライセンス、原典URLが明確か |
| 継続性 | APIや配布ページが現在も利用可能か |

## 3. 現行スコア

| 項目 | 配点 | 判定材料 |
| --- | ---: | --- |
| 公式性 | 20 | 提供機関種別 |
| 鮮度 | 15 | 最終確認日 |
| 取得性 | 15 | 成功回数・失敗回数 |
| ライセンス明確性 | 15 | ライセンス名、商用利用可否 |
| 形式利用性 | 15 | JSON、GeoJSON、CSV等 |
| 土木建設関連性 | 20 | カテゴリ |

## 4. 表示例

| 項目 | 例 |
| --- | --- |
| 鮮度 | B |
| 完全性 | A |
| 地域網羅性 | C |
| 公式性 | A |
| 総合利用推奨 | 要確認 |

## 5. 禁止事項

| 禁止事項 | 理由 |
| --- | --- |
| 欠損値を推測して事実として補完する | 誤認につながる |
| 総合点だけで安全性を示す | 土木判断に必要な観点が消える |
| 出典不明データを公式扱いする | 追跡性が失われる |
| 古いデータを警告なしに表示する | 誤った判断につながる |
