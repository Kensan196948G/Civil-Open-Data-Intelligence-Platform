## 3. 代替可能／不可能範囲

| 業務 | 代替可能性 | 理由 |
| --- | --- | --- |
| 公開データ調査・台帳・横断検索 | ✅ CODIPが代替可能 | 競合製品に同機能なし。CKANはカタログだが土木特化・品質監視・空間分析が不足 |
| 地形・標高・傾斜・断面分析 | ✅ CODIPが代替可能 | GSI DEM実データ＋Horn/TPI。ANDPAD等は対象外 |
| 気象・海象・施工可否の確認支援 | ✅ CODIPが代替可能（確認支援として） | 競合に閾値判定・50年確率波なし。ただし最終判断は人 |
| 現場コミュニケーション・チャット | ❌ 代替不可（CODIPにない） | ANDPAD/ダンドリワーク/現場クラウドOneの領域 |
| 写真・資料・図面管理 | ❌ 代替不可 | CODIPに資産管理・承認ワークフローなし |
| 工程表・日報・検査・書類決裁 | ❌ 代替不可 | 現場クラウドOne・SC Groupwareの領域 |
| 入退場・KY・労務管理 | ❌ 代替不可 | ダンドリタイム等の領域 |
| データカタログ公開（組織外向け） | ⚠️ 部分代替 | CKANのハーベスト・DCAT等の標準規格対応が未実装 |
| 3D点群・土量計算 | ❌ 代替不可 | SC Groupware領域。PLATEAU 3D TilesはP2予定 |
| 監査・証跡・出典管理 | ✅ CODIPが強み | リネージュ・監査ログ・判定スナップショット |

## 4. 独自優位性

1. 🏗️ **土木建設×公開データ×空間分析の組み合わせ**が国内製品に存在しない
2. 🌦️ **気象海象×地形×データ基盤が同一UIで一体**（WMCDSS＋Slope Viewer統合）
3. 🛡️ **「人による最終判断」前提の安全設計**（自動断定しない・監査保存）
4. 💰 **低コスト・少人数運用**（Cloudflare＋Neon＋GitHub Actions、OSS中心）
5. 🔗 **後続システム向けAPI・空間評価・リネージュ**で社内システムと接続可能

---

## 5. 結論

CODIPは**施工管理SaaS（ANDPAD等）の代替にはならないが、公開データ×地形×気象海象の「調査・判断支援基盤」としては競合が存在しない独自領域**。  
競合の80%代替を目指すには、モバイル/PWA・通知・RBAC・PDF/Excel・コミュニケーション/承認ワークフロー等の追加が必要であり、Phase 2〜4（後述ロードマップ）で段階的に拡張する。
