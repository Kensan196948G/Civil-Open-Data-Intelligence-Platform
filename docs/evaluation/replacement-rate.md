## 1. 評価基準

機能の存在だけでなく、以下が揃った場合のみ「実用上カバー済み」と判定する。

- ✅ 正常系・異常系テスト
- ✅ RBAC（必要な権限分離）
- ✅ 監査ログ
- ✅ バックアップ
- ✅ 操作手順（Runbook/利用者向け手順）

### 3. 80%到達必須項目（本格展開の前提）

1. 🚧 モバイル/PWA対応（現場タブレット・スマホ）
2. 🚧 通知・ウォッチリスト（メール/Teams/Slack/Webhook）
3. 🚧 RBAC（閲覧者/技術者/データ管理者/監査/API利用者）
4. 🚧 PDF/Excelレポート出力
5. 🚧 監視アラート通知先・通知テスト（運用停止防止）
6. 🚧 実データ収集50種以上＋品質SLA
7. 🚧 コミュニケーション（現場掲示・コメント）最小実装

### 4. 90%到達項目（競合水準）

1. 📄 書類・写真・図面管理、承認ワークフロー
2. 📋 工程表・日報・検査・遠隔臨場
3. 🧭 DCAT-AP-JP/OGC API Features/GeoParquet/STAC対応
4. 🤖 AIによる文書・検索・異常検知支援（人間承認フロー付き）
5. 🗂️ 現場資産管理と既存SaaS（ANDPAD等）とのAPI連携

### 5. 意図的に代替しない機能

| 機能 | 理由 |
| --- | --- |
| 会計・給与・労務（入退場・勤怠） | 既存システム（DeskNet's NEO等）の領域。重複投資を避ける |
| 3D設計・点群処理・土量計算 | 専用CAD/SC系製品の領域。CODIPは判断支援データを提供 |
| メール・チャット基盤 | Microsoft 365/Teamsが正本。CODIPは通知連携先として利用 |
| ドキュメント管理の完全代替 | SharePoint Onlineが正本。CODIPは必要な帳票・判定レポートを生成 |
| 法令適合・施工可否の自動確定 | 法規上・安全上の最終判断は有資格者・担当者。CODIPは根拠提示まで |
