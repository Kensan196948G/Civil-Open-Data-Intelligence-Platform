# 用語集

| 用語 | 意味 |
| --- | --- |
| CODIP | Civil Open Data Intelligence Platformの略称 |
| 公開データ | 国、自治体、機関などが公開しているデータ |
| 公開API | 公開データを機械的に取得できるAPI |
| データソース | CODIPに登録する公開データまたはAPI |
| 台帳 | データソースのURL、形式、利用条件、品質等の管理情報 |
| 原本 | 公開元から取得した未加工データ |
| 標準化 | 公開元ごとに異なる形式を共通形式へ変換すること |
| 共通データモデル | 後続システムが同じ形式で使えるレコード形式 |
| コネクタ | 公開元ごとの差異を吸収する取得処理 |
| 取得ログ | 接続確認や取得処理の結果記録 |
| 品質スコア | 公式性、鮮度、取得性等を点数化した補助指標 |
| PostGIS | PostgreSQLで空間データを扱う拡張 |
| GeoJSON | 地理空間情報をJSONで表す形式 |
| Shapefile | GISで広く使われる地理データ形式 |
| EPSG:4326 | 緯度経度で表す代表的な座標参照系 |
| PLATEAU | 国土交通省の3D都市モデルプロジェクト |
| 地理院タイル | 国土地理院が提供する地図タイル |
| 後続システム | CODIPの共通APIを利用する別アプリケーション |
| AI生成フラグ | AIが作成した情報であることを示す印 |
